# Furniture Hates You

A 3D showroom survival game built with Godot 4.7. Cross a wide, winding furniture
course, avoid animated furniture, and climb through five raised showroom lanes.

## Controls

- **WASD** — move
- **Space** — jump
- **Left Shift** — sneak
- **F** — open the emote wheel; point at an emote and release
- **Esc** — pause or resume

The showroom uses wood, woven upholstery, and varied ceramic tile textures.
It features five terrace heights from 0 m to 5 m, long shallow collidable ramps
with guardrails, a marked start gate, and floor arrows through the winding route.
Furniture vignettes, patterned rugs, price tags, promotional signs, plants,
lamps, and scattered floor wear give each department a more lived-in showroom
feel. The game also includes an angled follow camera, cel-shaded materials, a
procedural player, death/respawn effects, and procedural sound effects. The
soundtrack alternates between the Goat Simulator and Spider-Man tracks, then
repeats continuously.
